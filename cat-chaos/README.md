# Cat Chaos — Remotion project

See the [repository README](../README.md) for setup, animation timing, validation and export instructions.

- `npm ci` installs locked dependencies.
- `npm start` starts Remotion Studio.
- `npm run check` validates TypeScript.
- `deliverables/` contains the finished MP4 and preview image.

Composition: `CatChaos`, 1080 × 1920, 30 fps, 6 seconds. Silent; all artwork is authored locally in SVG.
